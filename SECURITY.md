# Sécurité

Merci de ne pas publier de clé API, mot de passe, jeton d’appairage, contenu du presse-papiers ou détail exploitable d’une vulnérabilité dans une issue publique.

Pour signaler un problème de sécurité, utilise la fonction **Report a vulnerability** de l’onglet Security du dépôt GitHub. Si cette fonction n’est pas disponible, contacte le mainteneur via son profil GitHub : https://github.com/choco8exe.

Les journaux et captures peuvent contenir des chemins ou des données personnelles : vérifie-les et expurge-les avant de les joindre.
