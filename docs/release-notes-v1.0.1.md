# ORBIT OS 1.0.1

Première publication publique de Project Nebula.

Cette version réunit Mission Control, Echo, Pulsar, Core, Timeline et les intégrations facultatives. Elle comprend notamment le compagnon Stream Deck 1.0.0.2.

## Installation

- `ORBIT.OS_1.0.1_x64-setup.exe` : installateur Windows x64 (NSIS).
- `com.orbitos.creator.streamDeckPlugin` : compagnon Stream Deck, à installer dans Stream Deck si l’intégration n’est pas déjà présente.

Le setup n’est pas signé par Authenticode. Les mesures et intégrations dépendent de Windows, des pilotes et des permissions accordées. Cette version peut contenir des bugs ; signale-les dans les [Issues GitHub](https://github.com/choco8exe/orbit-os/issues).

Les vérifications disponibles pour cette build incluent la compilation frontend et Windows, les tests ciblés du pont natif et du compagnon, ainsi que la validation du paquet Stream Deck. Tous les parcours n’ont pas été vérifiés de bout en bout sur différentes machines.
