# Contribuer à ORBIT OS

Les retours, rapports de bugs et propositions de code sont les bienvenus. Pour signaler un problème ou discuter d’une idée, ouvre une **Issue** sur GitHub. Une **Pull Request** sert à soumettre directement un changement de code ou de documentation.

## Avant de commencer

1. Recherche une issue similaire et, pour un changement important, ouvre une issue pour discuter de l’approche.
2. Travaille sur une branche dédiée.
3. Garde les changements ciblés et explique le problème qu’ils règlent.
4. N’ajoute jamais de clé API, de mot de passe, de journal personnel ou de contenu du presse-papiers.

## Développement

Consulte les prérequis et les commandes de développement dans le [README](README.md). Les changements d’interface doivent rester utilisables au clavier, lisibles dans une fenêtre redimensionnée et cohérents avec Nebula Dark. Les mesures système doivent provenir du système ; les valeurs indisponibles doivent rester explicites.

Avant d’ouvrir une Pull Request, exécute les vérifications pertinentes au module modifié et indique leurs résultats dans la description. Les contributions Windows natives doivent être validées sur Windows lorsque c’est possible.

## Pull Request

Décris le changement, le contexte, les vérifications effectuées et les limitations restantes. Ajoute une capture pour les modifications d’interface si elle aide à les comprendre, en retirant toute donnée privée.
